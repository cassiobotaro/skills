   6  
   7  When an export is requested, the payload is validated. Requests above 100,000 rows are

  11

  15  
  16  ## Delivery
  17  
  18  Once the upload is done, a download link is sent by email. The link is expired after
  19  24 hours.
  20  
  21  ## Backups
  22  
  23  Backups of the bucket are rotated weekly.

### exporter/worker.py

```
   1  import json
   2  import os
   3  
   4  import boto3
   5  import pika
   6  from cryptography.fernet import Fernet
   7  
   8  from exporter.notifier import notify
   9  
  10  MAX_ATTEMPTS = 3
  11  
  12  
  13  def build_csv(job: dict) -> bytes:
  14      rows = [f"{job['account_id']},{n}" for n in range(job.get("rows", 0))]
  15      return "\n".join(rows).encode()
  16  
  17  
  18  def handle(channel, method, properties, body) -> None:
  19      job = json.loads(body)
  20      attempts = (properties.headers or {}).get("x-attempts", 0) + 1
  21      try:
  22          data = Fernet(os.environ["EXPORT_KEY"]).encrypt(build_csv(job))
  23          key = f"{job['account_id']}/{method.delivery_tag}.csv.enc"
  24          boto3.client("s3").put_object(Bucket=os.environ["EXPORT_BUCKET"], Key=key, Body=data)
  25          notify(job["account_id"], key)
  26      except Exception:
  27          target = "exports.dead" if attempts >= MAX_ATTEMPTS else "exports"
  28          channel.basic_publish(
  29              exchange="",
  30              routing_key=target,
  31              body=body,
  32              properties=pika.BasicProperties(headers={"x-attempts": attempts}),
  33          )
  34      channel.basic_ack(method.delivery_tag)
  35  
  36  
  37  def main() -> None:
  38      connection = pika.BlockingConnection(pika.URLParameters(os.environ["QUEUE_URL"]))
  39      channel = connection.channel()
  40      channel.basic_consume(queue="exports", on_message_callback=handle)
  41      channel.start_consuming()
  42  
  43  
  44  if __name__ == "__main__":
  45      main()
```

```
   1  # exporter
   2  
   3  Asynchronous CSV exports. A FastAPI gateway accepts export requests and queues them on RabbitMQ. A worker builds the CSV, encrypts it, uploads it to S3, and emails the account a download link.
   4  
   5  See [docs/pipeline.md](docs/pipeline.md) for the request lifecycle.
   6  
   7  ## How it works
   8  
   9  ```
  10  POST /exports → gateway → queue "exports" → worker → S3 (encrypted CSV) → SES email with presigned link
  11                                                 ↓ after 3 failed attempts
  12                                            queue "exports.dead"
  13  ```
  14  
  15  - **Gateway** (`exporter/gateway.py`): validates the payload and publishes it to the `exports` queue. Returns `202 {"status": "queued"}`.
  16  - **Worker** (`exporter/worker.py`): consumes `exports`, builds the CSV, encrypts it with Fernet, uploads it as `<account_id>/<delivery_tag>.csv.enc`, then calls the notifier. On failure it republishes the job with an `x-attempts` header. After 3 attempts it publishes the job to `exports.dead`.
  17  - **Notifier** (`exporter/notifier.py`): sends the account (`<account_id>@accounts.example.com`) an email containing a presigned S3 link that expires after 24 hours.
  18  
  19  ## Requirements
  20  
  21  - Python 3.12 or later
  22  - [uv](https://docs.astral.sh/uv/)
  23  - A RabbitMQ broker with the queues `exports` and `exports.dead` already created (the code does not declare them)
  24  - An S3 bucket and SES, with AWS credentials available to boto3 in the usual way
  25  
  26  ## Setup
  27  
  28  ```bash
  29  make setup
  30  ```
  31  
  32  ## Configuration
  33  
  34  Both processes read these environment variables:
  35  
  36  | Variable | Used by | Purpose |
  37  |---|---|---|
  38  | `QUEUE_URL` | gateway, worker, `scripts/requeue_dead.py` | AMQP URL of the RabbitMQ broker |
  39  | `EXPORT_BUCKET` | worker, notifier | S3 bucket for the encrypted files |
  40  | `EXPORT_KEY` | worker | Fernet key used to encrypt each file |
  41  | `MAIL_FROM` | notifier | Sender address for the notification email |
  42  
  43  AWS credentials and region are taken from the standard boto3 configuration.
  44  
  45  ## Running
  46  
  47  ```bash
  48  make run-gateway   # uvicorn on port 8080
  49  make run-worker    # consumes the exports queue
  50  ```
  51  
  52  Request an export:
  53  
  54  ```bash
  55  curl -X POST localhost:8080/exports \
  56    -H 'content-type: application/json' \
  57    -d '{"account_id": "acct-123", "rows": 500}'
  58  ```
  59  
  60  | Status | Meaning |
  61  |---|---|
  62  | `202` | The job was queued |
  63  | `422` | `account_id` is missing |
  64  | `413` | `rows` is above 100,000 |
  65  
  66  ## Dead-letter queue
  67  
  68  Jobs that fail three times land in `exports.dead`. The `ExportsDeadLetterHigh` alert (`deploy/alerts.yaml`) pages when more than 10 messages sit there for 5 minutes.
  69  
  70  To move them back to `exports`:
  71  
  72  ```bash
  73  uv run python scripts/requeue_dead.py --dry-run    # count only, move nothing
  74  uv run python scripts/requeue_dead.py --limit 50   # move at most 50 (default 100)
  75  ```
  76  
  77  Requeued messages are published without the `x-attempts` header, so they get three new attempts.
  78

  82  make test
  83  ```
