Return ONLY a JSON array, no prose around it, with one entry per check listed under
"Checks", in the same order:

## The user's message

Nosso template de design doc tá em docs/design/TEMPLATE.md — segue ele à risca, o time de arquitetura só aceita doc nesse formato. Preciso do doc do nosso novo serviço de deduplicação de eventos. Hoje o pipeline de ingestão recebe eventos duplicados dos produtores (reenvio em retry): medimos 4% de duplicatas no mês passado, e isso infla os relatórios de faturamento, o financeiro já reclamou duas vezes. A proposta é um serviço que fica entre o ingestor e o Kafka, guarda a chave idempotente de cada evento no Redis por 24h e descarta repetidos. Trade-off aceito: mais um salto no caminho crítico da ingestão, estimamos +5ms de latência. Meta: duplicatas abaixo de 0,1%. Autor sou eu, Rafael Nunes. Salva em docs/design/.
