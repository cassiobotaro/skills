Quero criar o workspace.dsl na raiz deste repositório para o sistema Encurtaí, nosso encurtador de URLs interno. Funciona assim: usuários da empresa acessam um SPA em React (servido por nginx) que chama uma API REST escrita em Go (Gin). A API grava e lê os links num PostgreSQL 16 e usa um Redis 7 como cache de redirecionamentos. Existe também um worker em Go que consome eventos de clique de uma fila RabbitMQ (publicados pela API) e grava métricas agregadas no mesmo PostgreSQL. O sistema todo é do nosso time; o único sistema externo é o Google Workspace, que a API usa para autenticação SSO dos usuários. Gere o diagrama de contexto e o de containers, com estilos pra diferenciar banco, fila e sistema externo, e um diagrama dinâmico mostrando o fluxo de redirecionamento de um link (usuário acessa link curto, API consulta cache, em caso de miss consulta o Postgres, e publica o evento de clique na fila).
