# 1. Registrar decisões de arquitetura

Date: 2025-11-10

## Status

Accepted

## Context

Precisamos registrar as decisões de arquitetura tomadas no sistema de faturamento para que novos integrantes do time entendam o histórico e o racional das escolhas.

## Decision

Vamos usar Architecture Decision Records, conforme descrito por Michael Nygard, mantidos em `docs/adr` neste repositório.

## Consequences

Toda decisão arquitetural relevante deve gerar um novo ADR numerado. Decisões substituídas devem ser marcadas como "Superseded" com link para a decisão que as substitui.
