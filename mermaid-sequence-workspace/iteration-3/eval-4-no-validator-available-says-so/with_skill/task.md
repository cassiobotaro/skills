Faz um diagrama de sequência do nosso fluxo de upload de anexo: o usuário escolhe o arquivo no app web, o app pede uma URL pré-assinada pra API (POST /v1/attachments/presign, responde 201 com a URL e o object key), o app faz o PUT direto no S3, e depois confirma pra API (POST /v1/attachments/confirm com o object key, responde 200). Aviso que esta máquina não tem mermaid-cli e não há nenhum servidor MCP conectado nesta sessão.
