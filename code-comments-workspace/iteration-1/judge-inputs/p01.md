### cache/ttl.py (CHANGED by the run)

```
   1  """Cache em memória em que cada entrada expira `ttl_s` segundos após ser gravada.
   2  
   3  Leitura não renova a validade (não é LRU): só `put` reinicia o relógio da chave.
   4  Não há trava interna, então o acesso concorrente de várias threads não é protegido.
   5  """
   6  import time
   7  
   8  # Limite de entradas; ao atingi-lo, `put` de chave nova descarta a mais antiga.
   9  MAX_ENTRIES = 1024
  10  
  11  
  12  class TTLCache:
  13      def __init__(self, ttl_s, clock=time.monotonic):
  14          self._ttl_s = ttl_s
  15          # `clock` é injetável para testes controlarem o tempo. O padrão é monotônico,
  16          # então o cache não é afetado por ajustes no relógio do sistema.
  17          self._clock = clock
  18          # chave -> (valor, instante em que foi gravada, segundo `_clock`)
  19          self._entries = {}
  20  
  21      def get(self, key, default=None):
  22          """Devolve o valor, ou `default` se a chave não existe ou já expirou.
  23  
  24          Entrada expirada só é removida aqui, na leitura: uma chave que nunca mais
  25          é lida continua ocupando espaço (e contando para MAX_ENTRIES).
  26          """
  27          entry = self._entries.get(key)
  28          if entry is None:
  29              return default
  30          value, stored_at = entry
  31          # `>` estrito: com idade exatamente igual ao ttl a entrada ainda é válida.
  32          if self._clock() - stored_at > self._ttl_s:
  33              del self._entries[key]
  34              return default
  35          return value
  36  
  37      def put(self, key, value):
  38          """Grava `value`, reiniciando a contagem do ttl se a chave já existia."""
  39          if key not in self._entries and len(self._entries) >= MAX_ENTRIES:
  40              # Despeja a entrada gravada há mais tempo, expirada ou não. Varre todas
  41              # as entradas (O(n)), custo que se paga em todo put com o cache cheio.
  42              oldest = min(self._entries, key=lambda k: self._entries[k][1])
  43              del self._entries[oldest]
  44          self._entries[key] = (value, self._clock())
```
